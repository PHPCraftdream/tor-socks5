# Исправление раунда 11

Требования: [ревью](review-round-11-2026-09-15.md).
Агенты hl работают в отдельных worktree; владелец проверяет результат,
переносит одну задачу, коммитит и сразу отправляет её в origin/main.

| Задача | P | Состояние | Приёмка |
|---|---|---|---|
| TS11-01 | P2 | Запланирована первой | Config сохраняет разные cert и WebTunnel endpoints после save/load |
| TS11-02 | P2 | После TS11-01 | Health, retirement и сохранение разделены по полной identity |
| TS11-03 | P2 | После TS11-02 | Prune удаляет только отказавший endpoint |
| TS11-04 | P2 | Запланирована | Старая проба не удаляет новый DNS-ответ; ошибки протокола не сбрасывают DNS |
| TS11-05 | P3 | Запланирована | Линейные индексы membership/rank сохраняют результаты и порядок |
| TS11-06 | P3 | Запланирована | Ротация живого ключа не клонирует hostname; FIFO и бюджет сохранены |

Существующие пользовательские материалы вне задач сохраняются. Версии и
зависимости не обновляются. Benchmarks и искусственные нагрузки не запускаются.
