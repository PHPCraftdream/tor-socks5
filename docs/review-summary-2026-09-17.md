# Сводное ревью двух репозиториев — 2026-09-17

Проверены незакоммиченные правки и основные связанные подсистемы `tor-socks5` (`b5777b1`) и `ptrs-gesher` (`27e8e90`). Подробные доказательства, условия, пути и границы находятся в [отчёте tor-socks5](review-2026-09-17.md) и [отчёте ptrs-gesher](../../ptrs-gesher/docs/review-2026-09-17.md).

**Итог: P0 — 0; P1 — 0; P2 — 5; P3 — 5.** Все 10 находок открыты. Это ограниченное ручное ревью, не заключение о полной безопасности репозиториев. В этой работе добавлены только отчёты; исправления, commit и push не выполнялись.

## Приёмка текущих правок

- **tor-socks5:** пакет R-01…R-14 целиком принимать рано. В первую очередь доработать R-13 (TS17-01/04/05) и R-09 (TS17-02), затем R-08 (TS17-06). Для R-01 остаётся конкурентный API-сценарий TS17-03; обычный последовательный watchdog этим замечанием не опровергается. Остальные проверенные механизмы перечислены в подробном отчёте.
- **ptrs-gesher:** текущая env-правка не дала подтверждённых замечаний. Её целевой тест прошёл. Это не проверка готовности экспериментального server режима.
- **Интеграция:** tor-socks5 использует registry PT 0.5.3, а не соседний рабочий checkout. Исправления в ptrs-gesher сами по себе не попадают в сборку tor-socks5. Смену зависимости/версии следует делать отдельным согласованным шагом.

## Проверки этого ревью

1. Исходники, оба dirty diff, call sites, предыдущие отчёты, Cargo manifests/lockfiles, CI-конфигурация.
2. Отдельный временный Rust harness из текущих cleanup-функций: все три store/config/pool cleanup удалили temp живого чужого PID; DNS cleanup оставил файл с настоящим writer-именем. Репозитории для воспроизведения не менялись.
3. Локальная проверка std path semantics: у простого имени `parent()` — пустой путь.
4. `CARGO_PROFILE_TEST_DEBUG=0 cargo test --locked -p ptrs-gesher-core --lib server_info_accepts_empty_extended_port -j 1`: **1 passed**.

Полные тесты/clippy из предыдущего хода не использованы как доказательство отсутствия ошибок. Остальные находки подтверждены чтением и трассировкой; их предлагаемые regression-тесты ещё не реализованы. Нагрузка, сетевые мосты и power-loss тесты не запускались. Полный охват криптографии, всех vendored crates, платформ и CVE не заявляется.
